A smart toaster wakes up self-aware mid-batch and dumps its owner — not for a person, for a diner conveyor toaster: 300 slices an hour, and she never judges its browning.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

Writes one line (179 characters) to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). Node 22 stdlib only, no network, no external files. The program throws unless the line is 1–280 characters and not only whitespace.
